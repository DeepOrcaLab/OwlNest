# OwlNest

OwlNest 是一款開源 AI 瀏覽器擴充功能，協助你更有效率地閱讀網頁、理解外語內容與學習影片知識。它將 AI 閱讀、智慧翻譯、影片字幕、頁面感知 AI Agent 與個人知識庫整合到瀏覽器中，讓你從理解內容到累積知識都無須頻繁切換工具。

- **AI 閱讀**：摘要網頁、提煉重點、解釋術語與複雜段落。
- **智慧翻譯**：支援選取文字翻譯、整頁翻譯與雙語閱讀。
- **影片字幕**：為課程、演講與知識型影片提供字幕與翻譯輔助。
- **內建 AI Agent**：無須切換頁面，即可圍繞目前網頁或影片提問、補充資料、核查觀點與整理學習重點。
- **個人知識庫**：將有價值的網頁內容儲存於本機，自動產生標籤與主題；之後可搜尋、回顧，並依據已儲存資料繼續提問。
- **語音互動**：支援語音提問與內容朗讀，適合通勤和沉浸式學習。

> 不只協助你讀懂眼前的網頁，也協助你將值得保留的資訊沉澱成可持續使用的個人知識庫。
